# AVISO — Dependência externa

Esta pasta deve conter os arquivos do **Java Access Bridge 2.0.2**, obtidos diretamente da fonte oficial da Oracle.

**Os arquivos binários não são distribuídos neste repositório.** O usuário é responsável por obtê-los e verificar os termos de licença aplicáveis à versão utilizada.

Após a instalação, confira se os arquivos estão no diretório esperado antes de executar o worker.
